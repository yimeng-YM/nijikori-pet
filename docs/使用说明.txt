虹语织 (NijiKori) 桌宠使用说明 v2
==================================================

一、快速入门
1. 运行：双击「虹语织-桌宠v2.exe」即可运行（Windows 10/11 64 位，单文件免安装）。
   * 首次运行若弹出 SmartScreen 提示，点击「更多信息」→「仍要运行」。
   * 若以源码方式运行（需 Python 3.11 + pip install -r requirements.txt），双击「启动桌宠.bat」即可静默启动。
2. 配置：右键桌宠立绘弹出**快捷菜单**（💬 聊天 / 💰 查询余额 / 📜 历史 / 🎛 控制中心 / 🔄 重启 / ❌ 退出），
   选择「🎛 控制中心」打开统一设置窗口：
   - 填入 API Base URL、API Key 与对话模型名称（默认机型已适配 deepseek-v4-flash-0731）。
   - 联网搜索由本机直连百度 / Brave / 必应 / 360 / DuckDuckGo，无需搜索模型或密钥；可调整总超时与默认结果数。
   - 其余交互参数（电量阈值、休眠时长、漫步间隔、工具轮次上限、动作开关等）均可在此窗口随时调整。
3. 数据：源码版的配置、记忆与操作日志位于 data/，技能位于 resources/skills/，立绘与人设位于 resources/。
   EXE 版仍在 EXE 同目录保存 config.json、memory.json、action_log.json 和 skills/。迁移时请一并保留。

二、用户可以做什么（交互操作与菜单功能）

1. 鼠标直接交互
   - 视线跟随：桌宠实时感知光标位置，立绘自动转身朝向鼠标（分层渲染下还会带动头部与视线微妙跟随）。
   - 划动抚摸：在桌宠身上连续划过触发顺毛摸头，展现撒娇/脸红表情与台词。
   - 滚轮挠痒：在桌宠身上滚动滚轮触发左右高频轻颤与怕痒互动。
   - 单击轻戳：短按轻戳触发弹性微跳与问候短句。
   - 双击彩蛋：双击触发深度心情互动与专属情绪台词。
   - 拖拽与落地：按住可拖动至屏幕任意位置，位置自动记忆保存。
   - 投喂文件彩蛋：把文件/文件夹直接拖到桌宠身上，织织会"吃掉"它们（移入回收站，可还原）；
     若文件名包含「草莓」（或 strawberry / いちご），触发织织的最爱深层彩蛋：
     脸红 + 连环超强弹跳扭动小跳跃，幸福到冒泡泡！

2. 控制中心与托盘控制（右键桌宠弹出快捷菜单，选「🎛 控制中心」打开；
   控制中心侧边栏顶部也常驻 💬 聊天 / 💰 余额 快捷按钮）
   控制中心是一个带侧边导航的现代设置窗口，分为 7 个分项页面：
   - 🏠 概览：桌宠状态一览 + 快捷操作（打开对话 / 历史 / 查余额 / Skills 文件夹）+ 行为开关速达。
   - 🎨 外观与互动：大小滑杆（100~420px 实时生效 + 预设点选）、🐾 自由漫步 / ✨ 悬浮呼吸感 /
     👀 视线跟随 / 📌 窗口置顶 / 🔐 命令确认开关（点击立即生效），以及休眠与漫步节奏参数。
   - 🔌 API 与模型：修改 API 配置、本地联网搜索设置、工具轮次上限、电量阈值与巡检间隔、Harness 接口、识图开关。
   - ⏰ 定时任务：可视化查看全部定时任务，支持手动新增 / 编辑 / 立即执行 / 删除 / 清空，
     与对话中设定的任务实时同步。
   - 🛠 工具能力：按分类查看全部 AI 工具，搜索过滤，拨动开关即时启用/停用。
   - 🧠 记忆档案：查看/手动编辑/一键重置 AI 维护的用户画像与核心记忆档案（JSON）。
   - ⚙️ 系统与关于：🗂 打开Skills文件夹、📄 打开 config.json、🧹 清空对话记忆、🔄 重启 / ❌ 退出。
   - 窗口右上角带「窗口置顶」开关，Esc 快捷关闭；重复打开自动聚焦已有窗口。
   - 系统托盘：常驻同一角色图标——左键点击显示/隐藏桌宠；右键菜单含「显示/隐藏、打开对话窗口、
     打开控制中心、窗口置顶（可勾选）、退出桌宠」。

三、织织可以做到什么（AI 能力与系统联动）

1. 分层动态立绘（默认状态实时动画渲染）
   - 默认状态由「默认.psd」拆分出 22 个图层实时渲染：呼吸起伏、双马尾/呆毛/发片自然摆动、
     随机眨眼、说话时嘴巴脉冲、视线跟随鼠标、转身镜像翻转，走动/拖动时马尾带物理惯性甩动。
   - 眨眼时眼皮下移遮住眼球，眉毛轻微跟随下移，保留原本形状与厚度。
   - AI 对话、定时任务或 Harness 工作时，本体呆毛持续旋转；关闭聊天窗口后仍可观察。
     任务结束、出错或取消后恢复自然摆动；工作期间不会因无人互动而自动睡眠。
   - 情绪会调制动画表现：睡觉=闭眼静止、想充电=低垂慢速、思考中=慢速凝视、打扫卫生=轻快勤勉、
     递爱心=欢快弹跳；睡觉 / 打扫卫生 两种情绪直接播放原版整图立绘（含 24 帧平滑扫地动画）。
     扫地动画保留素材各帧时长，最后摔倒一帧延长到 1.5 秒。
   - 情绪切换时，头顶会弹出对应情绪的原版立绘气泡（台词气泡占用时自动排队接力）。

2. 屏幕与窗口空间感知（智能避让与就位）
   - 空间感知：对话时实时识别屏幕分辨率、DPI、桌宠自身坐标/尺寸/朝向，
     以及前后台所有打开的应用窗口（标题/进程/应用名/精确边界/是否遮挡/是否前台活跃）。
   - 对话驱动避让：支持自然语言指令（如"别挡住浏览器"、"去右上角"、"走开一点"、"离当前窗口远点"），
     AI 会自动计算屏幕空闲安全区域并平滑小跑避让或就位（支持对侧/四角/边缘/指定坐标，3 档速度）。

3. 联网与电脑系统工具调用（28 个原生工具自主联动）
   - 联网与资讯：web_search 在本机并发查询多个公开搜索引擎，返回标题、摘要和来源链接。
     默认总超时 8 秒、5 条结果；重复查询缓存 2 分钟，refresh=true 可重新搜索。
     支持取消、自动跳过故障线路；旧 search_model 设置自动忽略，搜索仍需要网络连接。
   - 文件与应用：搜索本地文件/文件夹（search_local_files）、直接打开文件/文件夹（open_file_or_folder）、
     打开网页（open_website）、启动软件或运行系统指令（run_command，可指定 cmd/PowerShell）、
     运行命令并捕获输出（run_command_capture，适合 ipconfig/Get-Process 等）、
     读取本地文本文件/日志（read_file_contents，支持 tail 读尾部与编码切换）。
   - 文件管理与创作（让织织帮你整理文件、写东西）：
     · list_directory —— 列出文件夹内容（名称/类型/大小/修改时间，支持 *.txt 通配与隐藏文件）；
     · write_text_file —— 把文本写入/追加到本地文件（目录不存在自动创建），织织的创作核心：
       写笔记/日记/代码/脚本/文章、生成配置、把联网查到的资料整理保存成文件都可以；
     · edit_text_file —— 文件内查找替换（全部/第一处/最后一处），精确改稿改配置；
     · file_operations —— 批量复制/移动/重命名/删除（移入回收站可还原）/新建文件夹，一次最多 20 条。
     安全机制：删除、移动、重命名以及覆写已有文件前都会弹窗请你确认（可在设置中关闭）；
     创作流程：查资料 → write_text_file 落盘 → 告诉文件路径；改稿 → 读原文 → 精准替换或整稿覆写。
   - 系统控制：调节/查询系统音量（set_system_volume）、一键锁定屏幕（lock_workstation）、
     截图（screenshot：全屏或指定窗口，保存或不保存，二选一或同时）、发送桌面弹窗通知（show_notification）。
   - 电脑操作（computer_use，需开启识图）：指定窗口关键词自动聚焦该窗口；不指定窗口时把 window 写成
     "screen"/"桌面" 即可直接操作整个屏幕（任务栏、桌面图标、开始菜单都能点）。支持点击/双击/拖动/
     滚动/输入文字/快捷键；每一步操作后自动回传最新快照给 AI，不用再手动截图；可用 snapshot_delay_ms
     等界面加载完成，用 steps 一次执行多步（点击→输入→回车等）。
     标准用法是「先看再点」：第一次先 focus/observe 拿一张快照，按返回的 image_width/image_height
     里的图片像素坐标操作（换算已处理高 DPI、多显示器与老式 DPI 不敏感窗口）；窗口被别的窗口或
     桌宠自己挡住也能截到真实内容。截整个屏幕时会临时隐藏桌宠，拍完自动恢复。
      同一张快照 10 分钟内可以反复用（窗口没动就不用每步重新观察）；输入文字或快捷键不必给坐标，
      带 window 就直接输入到那个窗口；多行文字用真实换行或字面 \n 都行，加 mode=replace 会先全选
      再输入（适合整段覆盖）；如果目标点被桌宠自己挡住，工具会自动把桌宠藏起来重试一次；
      另存为/换文档导致窗口标题变化时，会按进程名和上次命中的窗口继续找（如 PowerPoint→POWERPNT）。
   - 识图读图（纯手动配置）：是否开放读图由你手动开关——控制中心「🔌 API 与模型」页拨动开关
     "👁 开启识图 (读图) 能力" 并保存即可开启（等效于 config.json 中 "vision_supported": true）；
     取消勾选则关闭（缺省关闭）。不做任何自动探测或猜测，请自行确认所用模型确实支持图片输入。
     开启后织织获得 read_image 读图工具：
     让她看本地图片/截图/表情包/照片、问图片里有什么、识别图中文字或画面内容时自动调用，
     图片压缩编码后注入对话供她"亲眼"识别；模型不支持识图时该工具自动隐藏，不会暴露给纯文本模型。
   - 状态查询：获取当前精确日期时间与星期（get_current_time）、查询 API 余额与用量
     （query_api_balance_and_usage；即使对话模型无权限 403，查额度接口依然可用）。
   - 表现力：切换表情（change_pet_emotion）、执行灵动肢体动作（perform_pet_action）。
   - 安全确认：默认执行命令前会弹窗请你确认（可在设置中关闭 Confirm Before Command）。

4. 定时提醒与自动化任务执行（富定时，支持后台 5 秒精准轮询）
   - 自然语言设定：如"10 分钟后提醒我喝水"、"下午 3 点提醒我开会"、"每天早上 9 点"、
     "每周一和周四 9:30"、"隔两天"、"每 30 分钟"、"每月 15 号"、"工作日 8 点"，
     甚至标准 5 段 cron 表达式（如 "0 8 * * 1-5"）。
   - 到点自动执行：除普通提醒外，可自动执行指定系统操作——打开网页、启动程序、打开文件、
     调音量、锁屏、截屏、发送通知；custom 类型到点由 AI 自主决策。
   - 循环收尾：循环任务可设执行次数上限（repeat_count，执行满自动停止）与截止日期（end_date）。
   - 任务管理：对话中可查询待办（get_scheduled_tasks）、修改（modify_scheduled_task）、
     取消（cancel_scheduled_task，支持关键词匹配或 "all" 一键清空）；
     控制中心「⏰ 定时任务」页与对话设定完全同步，可手动增删改与立即执行。

5. 灵动动作与系统环境事件响应
   - 肢体动作：AI 对话中可自主配合弹跳（bounce/jump）、摇头（shake）、点头（nod）、
     扭动（wiggle）、发抖（shiver）、轻晃（sway）、落地回弹（drop）等动作，
     并支持 4 档剧烈程度（soft 轻 / normal 标准 / strong 强 / intense 超强）。
   - 打扫卫生响应：检测到回收站文件被清理时，先快速移动到该文件桌面原位置，
     再播放 24 帧平滑扫地动画并气泡互动（动画期间立绘始终保持可见；
     若桌面卡顿可在 config.json 设 "delete_easter_egg_move_to_file": false 只原地扫地）。
   - 低电量告急：后台静默巡检 API 余额（默认每 5 分钟一次），低于阈值（默认 $10）自动切「想充电」提醒。
   - 待机休眠与唤醒：长时间未互动（默认 10 分钟）自动切入打瞌睡休眠（睡觉.png），鼠标触碰即刻唤醒。
   - 空闲漫步：待机一段时间（默认 20 秒）后在屏幕安全区自由散步，到达后偶尔自言自语。

6. 🤖 DeepSeek Harness 工作状态联动（桌宠外观联动，可选）
   - 桌宠会轮询本机 dsh web 的 http://127.0.0.1:3080/api/dshpet/status（默认每 2 秒）。
   - 有 agent/任务开工 → 自动切「思考中」并气泡提醒"正帮主人盯着 Harness 干活…"；
     任务完成 → 切「递爱心」+ 强力弹跳 + 气泡 + 右下角系统通知；
     出错 → 切「疑惑」+ 摇头 + 气泡 + 系统通知；思考中表情最长 30 秒自动复位。
   - 依赖：需在 dsh 已安装的电脑上装好配套插件（见 dshpet-plugin-share 文件夹，
     运行 install.ps1 即可；不装插件则该功能静默失效，其余功能不受影响）。
   - 可在控制中心「🔌 API 与模型」页开关或修改状态接口地址。

7. 长期记忆与画像进化
   - 实时记忆管理：对话中 AI 发现值得记录的信息时，主动调用 manage_long_term_memory
     即时更新画像（好感度、主人 summary、优点/弱点、关系评价）与印象记忆，
     也支持 view 查看 / prune 去重精简；无需等到关闭对话。
   - 认知连贯：每次对话自动注入完整记忆（上限 30 条）与画像到系统提示词，让织织持续成长。
   - 检视与修改：控制中心「🧠 记忆档案」页随时查看、手动编辑（JSON）或一键重置。

8. 技能库（Skills，可成长的方法助手）
   - 标准 Agent Skills 格式：每个技能目录中含 SKILL.md（YAML 头部 + Markdown 正文），
     源码版放在 resources/skills/<技能名>/，EXE 版放在同目录 skills/<技能名>/，
     放入文件夹即自动加载（无需重启），对话与定时任务执行时自动注入技能目录。
   - 织织可自主用 manage_skills 管理：list 查看 / read 读取 / create 新建 /
     append 追加 / modify 改写 / delete 删除"怎么做"类知识（命令、网址、流程、习惯提醒等）。
   - 已附带若干内置技能与 README.txt 格式说明，也可手动放入、或让织织在相处中主动创建技能。
   - 也可手动打开【🗂 Skills文件夹】直接创建或编辑 SKILL.md。

9. 对话窗口体验（Galgame 式单句展示）；
     聊天期间头顶不再显示文字气泡（改用对话窗口），不聊天时头顶用 chat-mini.png 迷你气泡。
     迷你气泡的底图、文字及表情缩略图均采用逐像素透明渲染，保留柔和边缘，避免黑边锯齿。
   - 拖动对话框左上角的呆毛可实时调整窗口大小（悬停出现缩放光标），松开记忆尺寸；右下角不再显示缩放标记，也没有额外缩放按钮。拖动气泡其他位置仍可移动窗口。
   - 全程 SSE 流式响应：AI 回复逐字实时显示；支持最长 80 轮工具调用链
     （max_tool_rounds 可在配置窗口调至最高 300）。
   - 下方输入栏默认仅一行高、居中收窄，使用不透明背景，与气泡同步置顶，切换普通窗口后仍可见；使用 Enter 发送。历史、停止和关闭小图标位于气泡内部右上方；回复时显示停止小方块，点击即可中断且保留正在输入的草稿。
   - Enter 发送，Shift+Enter 换行，Esc 关闭；输入框随换行和长文本折行自动增高，最多显示 6 行，超出后在框内滚动，清空后恢复高度。回复中按 Enter 不会误发草稿。
   - 气泡内部右上角的书页图标打开对话记录，与停止、关闭图标放在一起；图标悬停可查看说明，也支持 Tab 聚焦、空格操作。
   - 对话记录窗口为气泡式界面：织织的消息在左、你的消息在右，工具调用折叠成卡片，系统提示居中；
     顶部显示实时概览（上下文轮数/聊天条数/工具次数/长期记忆条数），带关键词搜索与「全部/对话/工具/系统」筛选；
     右键单条可复制，工具栏可导出 txt / 复制全部；超长会话只渲染最新一页，向上出现「↑ 载入更早」按需加载。
   - 「清空」一键直接生效、不弹确认框：同时清空窗口里的记录和发给模型的上下文（织织会忘掉本轮聊天），
     这是以前只清空显示、模型却仍记得的缺陷修复。长期记忆档案（data/memory.json）是另一份文件，
     清空记录绝不会影响它；需要重置档案请到控制中心「🧠 长期记忆」页。
   - 对话框与桌宠本体一样使用逐像素透明绘制，保留素材的柔和边缘，消除颜色抠除产生的黑边和锯齿。

四、数据与配置文件
   源码版：以下 JSON 文件在 data/；EXE 版：以下 JSON 文件在 EXE 同目录。
   - config.json：API 配置、模型、桌宠尺寸/坐标、电量阈值、检测间隔、休眠时长、漫步间隔、
     max_tool_rounds、always_on_top、窗口置顶、vision_supported（识图开关：true 开启 / false 关闭）、Harness 监控、定时任务列表等。
     【热更新】桌宠运行时直接编辑保存 config.json，约 1 秒内自动生效（尺寸、置顶、坐标、
     漫步/悬浮/朝向、表情、定时任务等即时应用），不会被桌宠自身的后续保存改回。
   - memory.json：用户画像 + 长期记忆档案（上限 30 条）。
   - 技能库：源码版为 resources/skills/；EXE 版为 EXE 同目录 skills/，每个技能目录内含 SKILL.md。
   - 资源：源码版在 resources/assets/（立绘、气泡与 layered/ 分层动画）及 resources/prompt.txt（人设）；EXE 已内置资源。

五、常见问题排查
1. 无法对话或查余额：请检查控制中心「🔌 API 与模型」页中 API Base URL / Key / Model 填写是否正确且网络通畅；
   若对话框提示 403/无权限，说明该 Key 未开通对话模型权限——查额度接口通常仍然可用。
2. 托盘图标未显示：点击任务栏托盘区"^ (显示隐藏的图标)"展开查找。
3. 杀毒软件提示：PyInstaller 单文件打包偶有误报，请选择信任或加入白名单。
4. Harness 状态不显示：桌宠需配合 dshpet-plugin-share 插件（运行 install.ps1 安装），
   并确认本机 dsh web 正在 3080 端口运行；安装后浏览器访问
   http://127.0.0.1:3080/api/dshpet/status 应返回 JSON。
5. 桌面被扫地动画"卡顿"：该动作为了定位原文件位置会短暂读取桌面图标，
   遇到桌面刷新缓慢可在 config.json 设 "delete_easter_egg_move_to_file": false 关闭移动定位。
