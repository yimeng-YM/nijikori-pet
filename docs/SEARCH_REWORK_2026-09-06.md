# 本地联网搜索与关键词策略

联网搜索由 `src/pet_search.py` 在本机执行，直接访问百度、Brave、必应、360、DuckDuckGo 的公开搜索页面。搜索入口不接收聊天 API 地址、密钥或模型；旧 `search_model` 在加载配置时移除。聊天本身仍使用用户配置的对话模型。

最多同时运行三条搜索线路，遇到失败自动补充备用引擎；单次默认总超时 8 秒，可取消。失败线路冷却 60 秒，相同查询与条数缓存 2 分钟，缓存最多 128 条。网络线程有数量上限，不会因连续超时无限增长。返回标题、摘要、来源链接和检索时间，过滤广告/验证码页面、清理可解码跳转并去重。必应明显丢失后续关键词时舍弃该批结果。

`src/pet_search_prompt.py` 统一维护工具说明、query 字段说明与每轮提示词。规则在自定义人设和外部技能之后注入，因此保存过旧人设的用户也能使用新策略；普通对话和定时任务共用。关键词通常按“实体原名 + 目标内容 + 必要限定”组合，保留名称、报错、地点和版本，按需添加日期，避免过长聊天原文和不必要的引号/site:。普通搜索直接使用内置工具；不因外部技能示例再走搜索模型或 Exa 命令。工具参数及必要引用不受短台词字数约束。

检索时间不等于网页发布日期，摘要不代表已读取全文。公开引擎可能限流或要求验证码；工具无法保证每次查询可用，失败时明确返回错误。重要事实缺失或冲突时，提示 AI 核对实际来源。

## 源码交付

`python -B tools/package_source.py` 创建独立时间戳 ZIP，包含当前源码、素材、技能、测试和说明，并附逐文件哈希清单。不会把本机配置、记忆、操作日志、构建缓存或 EXE 打进源码包；示例配置的 API Key 必须为空。发布完成后校验 ZIP CRC 与逐文件 SHA-256。

工作区清理将约 111.55 MiB 的构建缓存、Python 缓存和调试文件移出项目目录，保留在同盘的可恢复归档中，路径见 `workspace-cleanup-2026-09-06.json`。历史审查文档整理到 `docs/reviews/`；调试脚本、旧技能及重做前的代码另有压缩备份保存在 `release/archive/`。个人配置、记忆、当前技能库和历史发布保留。
