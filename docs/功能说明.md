# 虹语织 (NijiKori) - Windows 原生桌面萌宠与 API 助手

> 拥有 10 种丰富表情立绘（含 24 帧平滑打扫动图）、支持透明悬浮、自由置顶拖拽、OpenAI 原生 Tool Calling 工具自主调用、整场会话长期记忆与用户画像认知系统、自动休眠待机与桌面环境事件响应的 Windows 原生桌宠应用。

---

## 🪟 全新控制中心 (Modern Control Center)

- **⚡ 快捷菜单**：**右键桌宠弹出圆角快捷菜单**——💬 与织织聊天、💰 查询 API 余额、📜 对话历史**一键直达**，另含 🎛 控制中心 / 🔄 重启 / ❌ 退出；高频操作无需进窗口二级查找，点击空白处或 Esc 关闭。
- **一整个窗口，分项管理**：从快捷菜单 / 托盘菜单打开「虹语织 · 控制中心」——原本分散在右键菜单与 4 个独立窗口（参数配置 / 长期记忆 / 管理工具 / 定时任务管理）里的全部设置，统一收进一个现代侧边导航窗口，分为 7 个页面：
  - **🏠 概览**：桌宠状态一览（表情 / 大小 / 坐标 / 启用工具数 / 定时任务数 / 记忆条目）+ 快捷操作（打开对话、历史、查余额、Skills 文件夹）+ 行为开关速达；
  - **🎨 外观与互动**：桌宠大小滑杆（100–420px 实时预览 + 预设一键点选）、漫步 / 悬浮 / 视线跟随 / 置顶 / 命令确认开关、休眠与漫步节奏参数；
  - **🔌 API 与模型**：接口地址、API Key（可切换明文）、对话模型（无默认值，按所用供应商的模型 ID 填写）、本地联网搜索设置、工具循环上限、电量巡检阈值、Harness 监控与识图开关；
  - **⏰ 定时任务**：与 AI 工具实时同步的任务表格，支持新增 / 编辑 / 立即执行 / 删除 / 清空；
  - **🛠 工具能力**：按分类分卡片展示全部 AI 工具，搜索过滤 + 现代拨动开关即时启停；
  - **🧠 记忆档案**：长期记忆与用户画像 JSON 编辑器，一键保存 / 重置；
  - **⚙️ 系统与关于**：打开配置文件 / Skills 文件夹 / 程序目录、清空会话、重启与退出。
- **现代组件**：侧边胶囊导航（悬停高亮 + 选中态描边，品牌区常驻「💬 聊天 / 💰 余额」快捷按钮）、iOS 风格动画拨动开关（滑块补间 + 颜色渐变）、**自绘圆角滑杆**（拖拽 / 点击跳转 / **滚轮微调**，进度填充 + 悬停放大旋钮）、柔白圆角卡片分组、白底扁平输入框、悬停反馈圆角按钮；全部页面支持**鼠标滚轮滚动**，窗口右上角带「窗口置顶」开关，Esc 快捷关闭，重复打开自动聚焦已有窗口。
- **开关即改即存**：行为类开关拨动后立即生效并写入 `config.json`，无需保存按钮；API 文本类配置集中「保存并应用」。
- 系统托盘菜单同步新增「打开控制中心」入口。

## 🎨 柔彩气泡风界面 (Pastel UI)

- **与织织聊天时**：对话窗口使用 `chat.png` 素材作为对话框，以与桌宠本体相同的逐像素透明方式绘制素材、台词和图标，消除颜色抠除带来的黑边与锯齿。下方保留居中、低高度的不透明单行输入栏，使用原生编辑控件保留光标、选区及输入法功能。输入栏与气泡同步置顶，切换普通窗口后仍可见。历史、停止和关闭小图标放在气泡内部右上方，停止图标仅在回复时出现；图标支持悬停说明与键盘聚焦。此时**不再在桌宠头顶显示文字气泡**。
- **多行输入**：Enter 发送、Shift+Enter 换行；输入框随手动换行、粘贴和自动折行增高，最多显示 6 行，更多内容在框内滚动；发送或删除后自动收回，手动设置的窗口基础尺寸保留。回复中可继续编辑草稿，Enter 不会误发，停止回复保留草稿。
- **不聊天时**：桌宠头顶的短句气泡使用 `chat-mini.png` 素材，底图、文字和表情缩略图一同逐像素透明渲染，保留柔和边缘，消除颜色抠除的黑边锯齿。按文字长度自动缩放 3 档宽度并自动换行；**字号自适应**——超出气泡文字区时逐级缩小字号，最多容纳约 160 字，基准字号随桌宠大小同步缩放。气泡继续跟随桌宠定位、显示和隐藏。
- **全局 UI 统一换新**：聊天窗口与控制中心全部采用柔白 / 薰衣草紫 / 青色粉彩主题；正文使用高对比深黛蓝文字（对比度约 8:1）保证清晰可读，圆角按钮带悬停反馈。
- **HiDPI 自适应**：启动时启用系统 DPI 感知，文字以原生分辨率渲染（不再被 Windows 拉伸模糊），全部窗口尺寸按 DPI 自动缩放。

## 🎮 对话交互（Galgame 式单句展示）

- 对话窗口一次只展示一条消息，且**只显示 AI 消息**（你的话仅记录在历史窗口；顶部无发送对象铭牌），台词直接绘制在气泡素材上——**无任何背景框**；
- **对话窗口大小可自由调整**：拖动**左上角的呆毛**即可实时缩放，固定对侧角落，输入栏随窗口移动和缩放；松开保存尺寸，下次打开自动恢复。右下角不显示缩放标记，没有额外缩放按钮。拖动气泡其他位置可移动窗口；
- 对话台词沿用头顶气泡的微软雅黑加粗风格，输入栏使用较小的常规字重，降低存在感；
- **任务状态可见**：AI 对话、定时任务或 Harness 执行期间，桌宠本体的呆毛持续旋转，关闭聊天窗口后仍能观察；结束、出错或取消后恢复自然摆动。执行任务时不会因长时间未互动而自动睡眠。
- **眨眼动作**：眼皮保持原有厚度向下移动并遮住眼球，眉毛轻微下移跟随，避免眼睛和眉毛一起被压扁。
- 点击气泡内部右上角的书页图标打开**对话记录窗口**（新版 canvas 气泡界面，实现见 `src/pet_chat_history.py`）：头像 + 发言人 + 时间的聊天气泡（织织在左、主人在右）、折叠成卡片的工具调用、居中的系统提示，一屏可读的内容比旧的纯文本记录多得多；顶部带**实时会话概览**（上下文轮数 / 聊天条数 / 工具次数 / 长期记忆条数）、**关键词搜索**与**全部/对话/工具/系统筛选芯片（带条数）**，支持右键单条或一键**复制**、**💾 导出记录**（txt 落盘）、滚动时出现**↓ 最新**回到最新一条，底部输入框可**继续旧对话**（消息与对话窗口实时同步）。超长工具调用（如 run_command 的巨型指令）自动按 200 字符截断显示并标注原文长度，记录条数上限 2000 条（FIFO）。为避免超长会话卡顿，窗口**只渲染最新一页（60 个块）**，向上滚动出现「↑ 载入更早」按钮按需加载，旧的 Tk Text 全量重绘方式已不再使用；
- **🧹 清空记录（一键真正清空上下文）**：点击记录窗口的「清空」**直接生效、不再弹任何确认框**——同时清空窗口里的显示记录与 `chat_history` / `session_messages`，织织不会再记得刚才聊过什么（此前只清空显示、模型仍记得，是历史遗留缺陷）；同时会打断进行中的回合并递增轮次令牌，被中断回合的迟到回复不会再把消息写回已清空的上下文。**长期记忆档案是另一份文件（`data/memory.json`），清空记录绝不会触碰它**，好感度、主人画像与长期记忆完全不受影响；需要重置档案请到控制中心「🧠 长期记忆」页；
- AI 采用**多轮工具循环 + 全程流式响应（SSE）**：回复逐字实时显示在对话窗口；思考型模型常先返回空正文 + 工具调用，织织会持续执行工具（默认最多 80 轮，支持 run_command / 批量操作等**长工具循环**，`max_tool_rounds` 可在控制中心「🔌 API 与模型」页直接修改，最高 300）直到拿到正式回复，不再出现"接收到啦"兜底语；
- **入站请求头**：仅当接口为 Kouri 官方域名（api.kourichat.com / api.kouri.chat 标准端口）时发送客户端标识 `User-Agent: NijiKori/3.0`（用于 Kouri 用量归因），其他域名不注入；对话/查余额/定时提醒/记忆总结的所有请求统一生效；
- **AI 电脑与本地联网搜索能力**：`web_search` 由本机直接查询百度、Brave、必应、360 与 DuckDuckGo，不调用搜索模型、不依赖聊天 API 的地址或密钥。最多 3 条线路并发，失败时自动补充备用引擎，短暂等待首选引擎后快速返回可用结果；中文优先百度，其他查询优先 Brave，失败线路暂时冷却。返回标题、摘要、来源链接与检索时间；自动清理跳转链接、去重，重复查询缓存 2 分钟，可用 `refresh: true` 强制刷新。默认总超时 8 秒、5 条结果，可在控制中心调整；支持中途取消。公开搜索引擎可能要求验证码或暂时限流，所有线路不可用时明确返回失败；摘要不等于网页全文。配合本地文件搜索、打开文件/文件夹、读取文本、打开网页、运行程序、截图与长期记忆工具完成资料查询与整理。
- **👁 识图（读图）能力（Vision，纯手动配置）**：是否开放读图由你在 `config.json` 中**手动设定**——`"vision_supported": true` 开启、`false`（缺省，默认关闭）不开启，不做任何自动探测或猜测（请自行确认所使用的模型确实支持图片输入）。开启后织织额外获得 `read_image` 读图工具：主人让她看某张图片/截图/表情包/照片、问图片里有什么、识别图中文字或画面内容时，织织自动调用 read_image 读取本地图片，图片会被压缩编码（长边自动缩放至 1568px、透明底平铺白底、超限自动降质）并以 OpenAI image_url 格式注入本回合对话，让模型真正"亲眼"看到图片内容后再回答。模型不支持识图时该工具自动隐藏（控制中心「🛠 工具能力」页中显示为"当前模型不支持识图"），绝不会暴露给纯文本模型；
- **📷 统一截图工具 `screenshot`**：原来的 `take_screenshot` / `capture_window` / `take_snapshot` 三合一。`target=screen` 截屏幕（`all_screens=true` 截所有显示器），`target=window` 加窗口关键词（标题 / 程序名 / 应用名，或 active）截指定窗口——按窗口离屏渲染，被其他窗口遮挡、最小化或桌宠自己盖住也能截到完整内容；`save=false`（默认）时图片只在内存里直接注入本回合给 AI 看，`save=true` / `save_path` 时保存 PNG（默认桌面按时间命名）。两种可同时用；识图关闭时仍可用来保存截图。
- **🖱 computer_use 电脑操作（需开启识图）**：直接指定窗口（标题/程序名/应用名或 active）即可自动聚焦，不用手写 PowerShell。支持 windows 列窗口、focus/observe、click / double_click / move / drag / scroll / type / key，**每一步操作后自动把目标窗口的最新快照注入本回合**，AI 直接看图决定下一步，不需要再手动截图和读图；`snapshot_delay_ms` 可等界面动画/加载完成，`steps` 可一次下发多步（每步返回一张新快照，最多回传最近 8 张）。坐标用快照图片像素，脚本自动换算屏幕坐标，并兼容 DPI 不敏感的老式窗口（避免点偏）。未开启识图时该工具不会暴露给模型。体验优化：**同一张快照 10 分钟内可复用多次**（窗口没动就不必每步重新 observe）；**`type`/`key` 不再要求坐标和快照**，带 `window` 就能直接输入，不带则输入到当前前台窗口；**多行文本**支持真实换行与字面 `\n`，`mode=replace` 先全选再输入可整段覆盖；**桌宠自己挡住目标点时会自动隐藏自己重试一次**（`pet_blocks`）；**窗口标题变化**（另存为、换文档）会自动回退到进程名并按上次命中的窗口接着操作，`PowerPoint`→POWERPNT、`Word`→WINWORD、`Edge`→msedge、`记事本`→notepad 等应用名可直接用；`steps` 支持 `double_click`/`input`/`keys`/`wait` 等与单步一致的写法，写错会列出合法动作。
- **🛠 文件管理与创作能力（新增 4 个工具）**：`list_directory` 列出文件夹内容（名称/类型/大小/修改时间，支持 `*.txt` 通配与隐藏文件）、`write_text_file` 将文本写入/追加到文件并自动创建目录（**织织的创作核心**：写笔记/日记/代码/文章/配置、保存搜索资料、生成脚本）、`edit_text_file` 文件内查找替换（all/first/last 精确修改）、`file_operations` 批量复制/移动/重命名/删除（移入回收站可还原）/新建文件夹（一次最多 20 条）。删除、移动、重命名与**覆写已有文件**前都会弹窗请主人确认；创作流程：查资料（web_search）→ 落盘（write_text_file）→ 改稿（edit_text_file 精准替换或整稿覆写）；
- **🧑‍💻 代码编辑与增强能力（pet_tools 增强包）**：
  - **代码导航**：`glob_files` 按通配模式找文件（支持 `**` 递归）、`grep_files` 按正则搜索文件内容（ripgrep 风格，自动跳过二进制与 .git/node_modules）；
  - **读改一体**：`read_file_contents` 升级为带行号 + 按行分页（offset/limit）+ 编码自动探测（utf-8/gb18030）+ 二进制拒绝；新增 `edit_lines` 按行号精准替换/插入/删除；`edit_text_file` 唯一命中校验 + 自动备份 + 变更行号反馈；
  - **命令执行**：`run_command_capture` 返回 exit_code、超时上限 600s、超长输出保留头尾；`start_background_command` / `read_background_output` / `stop_background_job` 让长测试/编译后台跑不阻塞对话；
  - **Harness 委托**：`delegate_to_harness` 把大规模重构/批量迁移等重型任务委托给本机 DeepSeek Harness 后台执行（`dsh --profile headless`），桌宠负责对话拆解、Harness 负责动手写代码，dshpet-bridge 插件同步播报委托事件；dsh 启动器多级自动定位（config 指定 → PATH → npm 全局 → npx 缓存扫描 → npx 回退），找不到时可在 `config.json` 设置 `"harness_dsh_path"` 为 dsh.cmd 完整路径；
  - 增强工具实现在独立包 `src/pet_tools/`（注册表化，主程序 dispatch 自动兜底路由）；
- **全新定时任务与提醒系统（富定时）**：支持用户设定定时任务与提醒（set_reminder / set_scheduled_task），可在定时到期时**自动执行特定工具与动作**（如打开指定网页、启动应用程序、打开文件、调节音量、锁屏、截屏、发送通知），并支持查询待办（get_scheduled_tasks）、修改任务（modify_scheduled_task）与取消任务（cancel_scheduled_task）；除一次性提醒外还支持**各种循环方式**：固定间隔（每 N 分钟/小时/天/周，如"隔两天"）、每天固定时间（"每天早上9点"）、每周星期几组合（"每周一和周四 9:30" / 工作日 / 周末）、每月几号（"每月15号"），以及标准 5 段 **cron 表达式**；循环任务可用 repeat_count（执行满自动停止）与 end_date（截止日期）收尾；控制中心「⏰ 定时任务」页可**手动**新增/编辑/删除/立即执行/清空全部任务，与聊天设置的任务实时同步；后台每 5 秒高频精准轮询，到点执行后 AI 汇报并附带下次执行时间；
- **灵动肢体动作与多档剧烈度**：AI 在切换表情（change_pet_emotion）或执行独立动作（perform_pet_action）时，可配合上下弹跳（bounce/jump）、左右摇头（shake）、点头认同（nod）、撒娇扭动（wiggle）、瑟瑟发抖（shiver）、悠闲轻晃（sway）等，并支持 4 档动作剧烈程度（soft / normal / strong / intense）；
- **💰 多供应商额度查询（query_api_balance_and_usage）**：按你填写的 `base_url` 自动探测账户额度，不再只认 OneAPI 计费接口——内置 OpenAI 计费接口（`/dashboard/billing/subscription` + `/dashboard/billing/usage`）、OneAPI / NewAPI 账户接口（`/api/user/self`）、DeepSeek（`/user/balance`）、OpenRouter（`/credits`，回退 `/key`）、硅基流动（`/user/info`）、Moonshot / Kimi（`/users/me/balance`）等常见路径，未收录的供应商也会按「域名优先 → 常见路径」顺序依次尝试（单次查询限时、限次，不会长时间卡住对话）。返回结果统一给出剩余 / 已用 / 总额、账户币种与到期时间，缺的字段留空不编造；余额告急（电量告急）按账户币种与阈值比较，人民币账户不再被当成美元。查询结果同时用于聊天回答、右键「💰 查询 API 余额」气泡与后台静默巡检。
- **默认模型**：不预置任何示例模型名，出厂 `model` 为空，由用户按所用供应商的模型 ID 填写；未填写时查额度接口仍可正常使用；

## 🧩 插件系统（用 .py 扩展或改写桌宠能力）

桌宠内核与能力解耦：把 `.py` 放进**插件目录**，就能给织织加新工具，或改写她已有的行为。
**源码版与 EXE 版完全同一套机制**——插件目录永远在程序目录旁（源码版 `plugins/`，EXE 版 exe 同级 `plugins/`，
便携、跟着 EXE 走），因此打包成 exe 后依旧可以即插即用。

| 能力 | 插件 API | 说明 |
| :--- | :--- | :--- |
| 新增工具 | `api.register_tool(name, schema, handler)` | 自动并入 `PET_TOOLS`、工具管理页与 AI 可见清单，模型可直接调用 |
| 接管已有工具（含内置） | `api.override_tool(name, handler)` | handler 拿得到 `call_original()`，可完全替换、也可在原结果上加工 |
| 包一层（不改原实现） | `api.wrap_tool(name, before=…, after=…)` | `before` 返回 dict 即短路，`after` 返回 dict 即替换结果；工具名写 `"*"` 作用于全部工具 |
| 改系统提示词 | `api.add_prompt_block(text, when=…)` | 注入人格补充、规则、上下文，可条件生效（支持传函数现算） |
| 加界面入口 | `api.add_menu_item` / `api.add_control_center_page` | 右键快捷菜单项 + 控制中心自定义页面（可用同款 UI 工具箱） |
| 改外观 | `api.register_emotion` / `api.register_action` | 注册新表情立绘（PNG/GIF/WebP）与自定义动作，并自动并入工具枚举 |
| 监听事件 | `api.on(event, callback)` | startup / shutdown / message / reply / tool_call / tool_result / emotion_change / action / schedule_run … |
| 存自己的数据 | `api.state` + `api.save_state()` | 落在 `data/plugin_state/<插件名>.json`（EXE 版在 exe 同级 `plugin_state/`） |

### 加载与安全

- 支持两种形态：单文件 `plugins/我的工具.py`，或文件夹 `plugins/名字/plugin.py`（可带自己的模块与资源）；
  以 `_` 或 `.` 开头的文件/文件夹一律不加载（示例就放在 `plugins/_examples/`）。
- 入口固定为 `register(api)`。**插件是任意 Python 代码**，等同于交出本机执行权限，
  因此新的（或内容变化过的）插件第一次加载时会弹窗列出插件名与路径，由主人勾选确认；
  确认结果按内容哈希记在 `data/plugin_trust.json`，之后静默加载。控制中心可随时开关单个插件。
- 插件加载失败只影响它自己：注册到一半会**完整回滚**（工具表、分类、提示词、菜单、页面、表情、动作、
  事件钩子全部撤销），失败原因显示在控制中心「🧩 插件扩展」页与 `data/plugins.log`。
- 插件接管的是"工具行为"；更外层的安全机制（工具禁用开关、删除/移动文件的确认弹窗、
  定时命令授权、识图开关）仍在插件之前生效，**插件改不掉它们**——这是有意设计。
- 热重载：控制中心「🔄 重新加载插件」或 AI 的 `manage_plugins action=reload`，
  会先卸载全部插件并把工具表回滚到基线，再重新扫描加载，不会产生重复注册。

### 三条使用路径

1. **手动**：把 `.py` 丢进插件目录 → 控制中心「🧩 插件扩展」→「🔄 重新加载插件」→ 确认一次即可。
2. **一键示例**：同页「✨ 启用示例插件」，把自带 3 个示例复制到插件目录并加载。
   示例分别是最小插件（`example_hello`）、接管与钩子（`example_override`）、
   外观与界面（`example_appearance`）。
3. **让织织自己写**：跟她说「写个插件实现 XXX」。她会读取技能库中的
   [「插件开发指南」](../resources/skills/插件开发指南/SKILL.md)，按模板落盘、`manage_plugins action=reload` 生效，
   再汇报加载结果。插件相关工具：`manage_plugins`（list / reload / enable / disable / open_folder / examples）。

## 搜索回归验证

`python -B -m unittest discover -s tests -v` 运行隔离的搜索解析、并发/超时/取消、缓存、配置迁移和工具调用检查。`python -B tools/check_web_search.py` 使用公开关键词执行真实联网冒烟测试（不读取 API Key），输出来源链接、耗时和缓存命中情况。

## 搜索关键词与提示词

`src/pet_search_prompt.py` 同时提供工具描述、query 字段说明和每轮系统提示；无论是否保存了自定义人设，普通对话与定时任务都会加载同一套搜索策略。优先使用“实体原名 + 目标内容 + 必要限定”的简短关键词，保留版本/地点/报错，按需加入真实日期；少用引号和 site:，跑题时先改写关键词，不反复刷新相同请求。角色台词的字数与格式限制不作用于工具参数和必要来源。

例如：`Python tkinter documentation`、`北京 天气预报`、`Python requests SSLError`。搜索摘要只用于发现资料；检索时间不代表文章日期，重要结论应核对来源。提示词改变不需要修改个人 config.json；data/config.example.json 继承 resources/prompt.txt，避免保存过时的人设副本。
