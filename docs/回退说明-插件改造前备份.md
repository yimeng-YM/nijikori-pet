## 第 1 层：git 仓库（推荐，支持逐行回退）

项目原本不是 git 仓库，本次已初始化并提交了原始状态。

| 项目 | 值 |
| --- | --- |
| 提交 | `5560a2c` |
| 提交信息 | `backup: 插件系统改造前的原始状态（基线：145 测试通过）` |
| 纳入版本控制的文件 | 119 个 |

常用回退命令（在项目根目录执行）：

```powershell
# 看改了什么
git status
git diff

# 只还原某一个文件（例如改坏了 main.py）
git checkout 5560a2c -- src/main.py

# 放弃全部改动，回到改造前
git reset --hard 5560a2c

# 想看某个文件改造前的原文
git show 5560a2c:src/main.py
```

> 说明：`dist/`、`release/`、`data/`（运行数据）、`__pycache__/` 依 `.gitignore` 不纳入版本控制，
> 因此 git 只管源码，不会碰到你的配置、记忆和已构建的 EXE。

## 回退优先级建议

1. 只是某个文件改错 → 用第 1 层 `git checkout 5560a2c -- <文件>`；
2. 想整体回到改造前 → 用第 1 层 `git reset --hard 5560a2c`，或用第 2 层整目录覆盖；
3. 源码目录整个丢了 → 用第 3 层 ZIP 解压还原。
