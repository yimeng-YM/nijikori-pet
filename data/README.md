# 本机运行数据

源码版自动在此读写：

- `config.json`：API 配置、外观、工具开关与定时任务。
- `memory.json`：长期记忆与用户画像。
- `action_log.json`：操作记录。
- `plugin_trust.json`：插件信任记录（每个插件的内容哈希与主人是否许可加载）。
- `plugin_state/`：各插件自己保存的数据（`<插件名>.json`），由插件通过 `api.state` 读写。
- `plugins.log`：插件加载与运行日志（最近 800 行）。

首次启动会使用程序默认值；也可先把 `config.example.json` 复制为 `config.json` 再填写配置。正在运行时通过控制中心打开配置文件，或直接编辑 `data/config.json`，约一秒内自动生效。

整理前位于项目根目录的这三个文件已迁入此处，内容保留。以后从旧源码升级，启动入口也会自动迁移根目录遗留数据；若两处都有同名文件，会停止迁移并列出冲突路径，需要核对后保留所需版本。

备份个人数据时请保留此目录、`plugins/`（自装插件）以及 `resources/skills/` 中自建的技能。源码发布包只收录本说明与空密钥示例，不收录实际运行数据。

EXE 版仍在 EXE 同目录保存数据（含上述插件信任、状态与日志文件），不使用源码项目的这个目录；插件目录也在 EXE 同级的 `plugins/`。
